      Step 3AI Hub

      The AI news, twice a day.

      A Python script on GitHub Actions reads about 40 sources at 7 AM and 7 PM IST, removes duplicates, tags each story by company and publishes it here.

      # scripts/sources.yaml
sources:
  - { name: "Anthropic news",  type: rss,         category: official }
  - { name: "Hacker News",     type: hn,          category: buzz, min_points: 50 }
  - { name: "arXiv cs.AI",     type: arxiv,       category: research }
  - { name: "AI funding",      type: google_news, category: market }
  # 40 sources, six sections, refreshed at 7 AM and 7 PM IST

      What's inside

      SectionWhat it covers
      Official updatesNew models and releases from the labs
      HeadlinesArticles from tech news sites
      Gossip and buzzHacker News, Reddit, rumours (marked unverified)
      ResearchNew papers from arXiv and Hugging Face
      New models and toolsTrending models and repositories
      Market and fundingFunding rounds, IPOs and AI stocks
      Feedback loop.Each run adds a short brief, flags what's new since the last edition, and shows which sources worked.
